# LiPO-Battery-Charger
This repository contains the LiPo Battery Charger PCB Design with the auxiliary files in Aultium Designer

**3D Model**
The PDF file contains the 3d model of the completed PCB board in different views.

**BOM**
This is the bill of materials used in the project, with supplier and part numbers and other necessary details

**LiPo Battery Drill L1-2**
This cam file contains the details of the drilling map for the fabrication process

**First Drill Map**
This is the main Gerber file that contains the details for fabrication

**First**
.PcbLib is the file that contains the PCB Library files
.PcbDoc is the file that contains the PCB Design
.SchLib is the file that contains the schematic library files
.SchDoc is the file that contains the schematic files
